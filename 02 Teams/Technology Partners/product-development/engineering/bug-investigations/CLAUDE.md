# bug-investigations

## What is in this folder

Structured write-ups of bugs investigated by the Technology Partners squad.
One file per investigation, named: YYYY-MM-DD-[short-description].md

## When to read

Check this folder before starting any new bug investigation.
A past investigation may have already identified the root cause or affected infrastructure.

## Format

All files follow .claude/writing-guides/bug-investigation-guide.md.
