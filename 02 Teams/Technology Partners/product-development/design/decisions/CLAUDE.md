# decisions

## What is in this folder

Closed design decisions with context and rationale.
Designers populate this organically when a significant decision is made.
One file per decision, named: YYYY-MM-DD-[short-title].md

## When to read

Read when a query involves a past design decision, why something looks the way it does,
or what alternatives were considered for a UI pattern.

## Format

Use this structure:
```
# Design decision: [Title] — YYYY-MM-DD

**Decision:** [What was decided]
**Alternatives considered:** [What else was evaluated]
**Rationale:** [Why this choice was made]
**Designer:** [Name]
**Initiative:** Integrations Marketplace
```
