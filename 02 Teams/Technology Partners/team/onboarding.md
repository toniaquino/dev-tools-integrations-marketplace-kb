# Technology Partners Squad — Onboarding

Welcome to the Technology Partners squad. This guide gets you set up.

## What this repo is

A shared knowledge base where the squad checks in work so AI agents always have the right context.
Engineers, designers, and the PM all contribute. You don't need GitHub to participate.

## Your role

| Role | How you contribute | Tools needed |
|---|---|---|
| PM / PO | Direct commits or PR review | GitHub |
| Engineer | Paste bug investigations or RFCs in squad Slack — PM commits | None (GitHub optional) |
| Designer | Share Figma links and research summaries in squad Slack — PM commits | None (GitHub optional) |
