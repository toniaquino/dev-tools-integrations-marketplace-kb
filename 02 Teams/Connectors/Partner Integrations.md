## Integration ownership models

Two distinct models show up across active integrations -- get this right before filing a new entry:
A third case is not an integration at all and is flagged below.

- **Bynder-owned integration:** Bynder holds a direct strategic commercial partnership with the platform, and the integration itself is built and maintained by a separately contracted development partner. Salesforce is the reference example, with a different development partner per product surface: CobraCRM builds DAM Connect, LWC, and Data Cloud; Royal Cyber builds Salesforce Commerce Cloud; Penfield Digital (now Assist NL) builds Salesforce Marketing Cloud. Contentful follows the same pattern, with Appnovation as the development partner. Full Salesforce / Strategic Integrations tracking lives in `02 Teams/Integrations/`, not here.
- **Partner-built integration:** the technology partner's own ecosystem builds and lists the connector directly (e.g. Akeneo, built by Dataggo).
- **Neither — a partner-programme listing with no connector behind it.** Bynder is listed in *the partner's* directory, describing a manual or extension-based workflow rather than a built integration, usually because the partner's API cannot support one. Braze is the reference example, and its entry below is filed here despite not matching this file's stated scope, because the demand, the history and the positioning risk all need one home. **Do not read a Braze-style entry as evidence an integration exists** — check the Type field first.

- **⚠️ A separate API defect surfaced in the same exchange and has not been logged anywhere.** BloxWeaver tested `translations` fields and locale headers in the sandbox and reported that **the API accepted the unknown fields but neither applied nor exposed localised names** — i.e. it silently accepted input it did not honour, returning success. That is a distinct problem from the missing feature: silent acceptance of unknown fields will cause partners to ship code they believe works. **No Jira ticket exists for either the gap or the silent-accept behaviour.**
