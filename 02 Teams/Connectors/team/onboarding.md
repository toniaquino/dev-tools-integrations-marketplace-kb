## How this repo works

This is a shared knowledge base. You don't need GitHub to contribute.
Post in the squad channel and tag the PM — they'll commit it.

For direct GitHub access, ask Toni Aquino.

## Your contribution path

**Engineers:** bug investigations and RFCs go in product-development/engineering/.
Use the templates in .claude/writing-guides/.

**Designers:** Figma links go in product-development/design/figma-index.md.
Research summaries go in product-development/design/research/.

**Everyone:** Corrections to any file — post in squad channel, tag the PM.
