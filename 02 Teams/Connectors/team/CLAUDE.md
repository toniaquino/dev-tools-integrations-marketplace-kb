# team

## What is in this folder

- onboarding.md: how to get set up as a new Connectors squad member
- how-we-work.md: team norms, decision-making, meeting cadences
- retros/: retrospective notes by date

## When to read

- onboarding.md: for any new team member setup query
- how-we-work.md: for questions about team process or norms
- retros/: rarely -- only when query specifically asks about past retrospectives
