# RFCs

## What is in this folder

Technical design documents for architecture and API decisions made by the
Connectors squad. One file per RFC, named: YYYY-MM-DD-[short-title].md

## When to read

Read specific RFC files when making architecture decisions or reviewing past
technical choices. Check here before proposing major infrastructure changes.

## Format

All RFCs follow .claude/writing-guides/rfc-guide.md.
