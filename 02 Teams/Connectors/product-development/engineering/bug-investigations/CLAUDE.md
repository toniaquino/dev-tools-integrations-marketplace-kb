# bug-investigations

## What is in this folder

Structured write-ups of past bugs investigated by the Connectors squad.
One file per investigation, named: YYYY-MM-DD-[INC-KEY]-[short-description].md

## When to read

Check this folder before starting any new bug investigation.
A past investigation may already cover the same root cause or affected system.

All bug investigations follow .claude/writing-guides/bug-investigation-guide.md.
