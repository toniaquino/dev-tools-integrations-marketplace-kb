# PRDs

## What is in this folder

One subfolder per active initiative. Each subfolder contains the PRD and
any supporting specs or decision records for that initiative.

## When to read

Read a specific initiative subfolder only when the query names that initiative.
Do not load all PRDs for a general product query -- read feature-index.yaml first.

## PRD format

All PRDs follow the format in .claude/writing-guides/prd-guide.md.
Apply pm-voice-guide.md alongside when writing in the PM's voice.
