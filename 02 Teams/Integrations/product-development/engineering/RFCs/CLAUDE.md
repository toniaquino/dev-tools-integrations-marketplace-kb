# RFCs

## What is in this folder

Technical design documents for architecture and API decisions
made by the Integrations squad.

## When to read

When making architecture decisions or reviewing past technical choices.
Check here before designing a new system integration or API pattern.

## File naming

YYYY-MM-DD-[short-title]-rfc.md
Example: 2026-04-01-webhook-delivery-guarantees-rfc.md
